Porovnávací test

Test sa zastaví a regulácia podľa izby sa hneď vráti do bežného režimu. Dni, ktoré už skončili, sa zachovajú. Zastaviť test?

Zmeria, koľko energie ušetrí regulácia podľa detskej izby; dni A (s reguláciou) a B (bez nej) sa striedajú.

Ako to funguje

V dňoch A beží regulácia podľa izby ako obvykle, v dňoch B je vypnutá a čerpadlo ide len podľa ekvitermickej krivky. Počas testu agent nič nemení a ostáva ochrana: keď je v detskej príliš teplo alebo zima, alebo čerpadlo hlási chybu, deň B sa preruší a regulácia sa vráti. V dňoch B môže byť v izbách o niečo teplejšie alebo chladnejšie. Test začne o najbližšej polnoci.

Cloudflare tunel

načítavam…
Bez tohto nastavenia sa cez Cloudflare nedá prihlásiť, funguje len heslo.
Nájdeš ich v Cloudflare Zero Trust → Access → Applications → Samsung Heat Pump AI Control → Overview → „Application Audience (AUD) Tag“. Team domain je adresa prihlásenia …cloudflareaccess.com. Stránka s nimi overuje podpis prihlásenia z Cloudflare a nikdy neverí holej hlavičke s e-mailom. Prázdne polia = overovanie vypnúť.

Sprístupní túto stránku z internetu cez tvoj Cloudflare tunel (cloudflared beží na tomto serveri). V Cloudflare Zero Trust nastav „Public hostname“ na http://localhost:80 a pred stránku daj Cloudflare Access (prihlásenie e-mailom), lebo stránka ovláda kúrenie.

Automatické nastavenie – stránka sama vytvorí tunel, DNS záznam a Cloudflare Access. Stačí API token (Cloudflare → My Profile → API Tokens → Create Token → Custom) s právami: Account · Cloudflare Tunnel · Edit, Account · Access: Apps and Policies · Edit, Zone · DNS · Edit, Zone · Zone · Read. API token sa použije len raz, ak nezaškrtneš jeho uloženie na server.
Alebo vlož hotový token tunela ručne
Uloží sa na server a späť sa už nezobrazí. Token nájdeš v Zero Trust → Networks → Tunnels → tvoj tunel → Configure.

Plánovač ohrevu vody
Ako to funguje

Po skončení okna sa cieľ vráti späť. Čerpadlo tak ohreje zásobník, keď je vonku teplejšie, a večer menej dohrieva.

Heslo

Čo agent smie meniť

Ako to funguje

V režime „Len radí“ agent každú hodinu vyhodnotí stav a navrhne zmeny, ale nič nezapíše. V režime „Riadi“ povolené zmeny aj zapíše do čerpadla. Minútovú reguláciu podľa detskej izby robí vždy firmvér čerpadla.
